# Worldguessr

Worldguessr is a fun and engaging game that challenges players to guess the location of artistic images from around the world. The game is inspired by Geoguessr but uses unique artistic representations instead of real photographs.

## Features

- **Artistic Images**: Explore a variety of artistic images that represent different locations globally.
- **Interactive Gameplay**: Players can interact with the game to make guesses about the locations depicted in the images.
- **Score Tracking**: Keep track of your score and statistics as you play.

## Getting Started

To get started with Worldguessr, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/worldguessr.git
   cd worldguessr
   ```

2. **Install Dependencies**:
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Run the Application**:
   Start the development server:
   ```bash
   npm start
   ```

4. **Open in Browser**:
   Navigate to `http://localhost:3000` in your web browser to start playing!

## Gameplay Instructions

- Upon starting the game, an artistic image will be displayed.
- Use the provided interface to make your guess about the location.
- Your score will be calculated based on the accuracy of your guess.
- Keep playing to improve your score and challenge your friends!
